# Contributing to NodeFlow

Спасибо за помощь с beta-версией NodeFlow.

## Перед созданием Issue

1. Проверьте, что проблема воспроизводится на актуальной версии Panel и Agent.
2. Не прикладывайте секреты: токены, ключи, сертификаты, UUID, реальные IP-адреса клиентов или полный конфиг ноды.
3. Для проблем маршрутизации добавьте обезличенный маршрут, ожидаемое и фактическое поведение, ОС ноды и версию HAProxy.

## Pull requests

- Один PR — одна задача.
- Не смешивайте изменения Panel, Node Agent и installer без необходимости.
- Для UI приложите скриншот; для Agent/installer — способ проверки.
- Перед отправкой выполните релевантные тесты и не добавляйте generated secrets или release artifacts.

## Идеи

Feature request должен объяснять эксплуатационную проблему и желаемый результат, а не только предлагаемый экран или кнопку.
