# NodeFlow 2.3.0

Panel **2.3.0** · Node Agent **2.3.0** · HAProxy renderer **v21**

English UI with a language switch, an English README and stable error codes in the API. No migrations. Thanks to @ANHELL404 (#21, #23).

## New

- **English UI.** The panel is now available in English (ru/en locales). Switch the language in the sidebar or on the login page; the HAProxy directive help is available in English too.
- **English README** — [README.en.md](../../README.en.md) and English release notes for 2.2.0 and 2.3.0.
- **Stable codes in the API.** Route copy errors, template apply errors and HAProxy lint messages now carry `error_code` and `message_key` with `message_params`; the built-from-routes note carries `note_key` (`built_from_routes`). The Russian `message` field is kept for compatibility.
- **`copy_suffix`** — route copy parameter that sets the suffix of the copy name.

## Fixes

- The Agent bootstrap script installs the binary into `/usr/local/bin` (#21, #23). Thanks to @ANHELL404.

## Upgrading

- No migrations.
- Agent code is unchanged — only the bootstrap script served by the Panel changed. Upgrading the Agent on existing nodes is optional; new installs get the fixed script right away.
