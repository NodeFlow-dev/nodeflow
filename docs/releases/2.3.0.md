# NodeFlow 2.3.0

Panel **2.3.0** · Node Agent **2.3.0** · HAProxy renderer **v21**

Английский интерфейс с переключателем языка, README на английском и стабильные коды ошибок в API. Миграций нет. Спасибо @ANHELL404 (#21, #23).

## Новое

- **Английский интерфейс.** Панель переведена на английский (локализации ru/en). Язык переключается в боковой панели и на странице входа; справка по директивам HAProxy тоже доступна на английском.
- **README на английском** — [README.en.md](../../README.en.md) и английские заметки к релизам 2.2.0 и 2.3.0.
- **Стабильные коды в API.** Ошибки копирования маршрутов, применения шаблонов и сообщения линтера HAProxy теперь содержат `error_code` и `message_key` с `message_params`; заметка о сборке из маршрутов — `note_key` (`built_from_routes`). Поле `message` на русском сохранено для совместимости.
- **`copy_suffix`** — параметр копирования маршрута, задающий суффикс имени копии.

## Исправления

- Bootstrap-скрипт установки Agent кладёт бинарник в `/usr/local/bin` (#21, #23). Спасибо @ANHELL404.

## Обновление

- Миграций нет.
- Код Agent не менялся — изменён только bootstrap-скрипт, который отдаёт Panel. Обновлять Agent на существующих нодах необязательно; новые установки сразу получают исправленный скрипт.
