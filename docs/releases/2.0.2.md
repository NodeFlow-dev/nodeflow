# NodeFlow 2.0.2

Panel **2.0.2** · Node Agent **2.0.2** · HAProxy renderer **v21**

Улучшение редактора маршрута.

## Изменено

- **Подсказки к весу и стоимости отдельных IP.** В таблице «Вес и стоимость отдельных IP» у DNS-пула заголовки «Вес» и «Стоимость» теперь с подсказкой при наведении, а над таблицей — строка с формулой и примером под текущий алгоритм. Для «Меньше соединений»: доля IP = вес ÷ стоимость, например, для серверов на 4 и 2 ядра — вес 2 у 4-ядерного (или стоимость 2 у 2-ядерного), и он получит вдвое больше клиентов. Подсказка к весу сервера тоже уточнена.

## Обновление

Повторно запустите `install.sh` или обновите образ до `ghcr.io/nodeflow-dev/nodeflow-panel:2.0.2`. Миграций нет. Node Agent обновлять не обязательно — изменений в агенте нет, 2.0.2 можно назначить в «Настройки → Node Agent» для единой версии.
