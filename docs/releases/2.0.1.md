# NodeFlow 2.0.1

Panel **2.0.1** · Node Agent **2.0.1** · HAProxy renderer **v21**

Исправление к 2.0.0.

## Исправлено

- **«Толерантность» пропадала после сохранения** на маршрутах, где единственный сервер — домен в режиме DNS-пула (например, `co-de…` со всеми его A/AAAA-адресами), а первый сервер выбирается «Меньше соединений». Панель сохраняла такой маршрут в старом формате одиночного маршрута, в котором нет полей алгоритма и толерантности, и при следующем открытии поле было пустым. Теперь маршрут остаётся пулом серверов: толерантность сохраняется, а агент каждые 5 с выравнивает веса адресов пула.
- Маршруты без толерантности и с закреплением по хешу IP клиента не меняются: конфигурация HAProxy для них рендерится байт в байт как в 2.0.0.

## Обновление

Повторно запустите `install.sh` или обновите образ до `ghcr.io/nodeflow-dev/nodeflow-panel:2.0.1`. Миграций нет. Node Agent обновлять не обязательно — 2.0.0 уже умеет толерантность; 2.0.1 можно назначить в «Настройки → Node Agent» для единой версии.

После обновления откройте затронутые маршруты, снова задайте толерантность и сохраните.
