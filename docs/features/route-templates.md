# Копирование маршрутов и шаблоны

В меню строки маршрута доступны:

- **Дублировать маршрут** — открыть заполненный редактор нового маршрута на
  этой ноде. Имя получает суффикс «копия». Изменения исходного маршрута не
  сохраняются в копию автоматически.
- **Копировать на ноды / сохранить шаблон** — выбрать одну или несколько нод
  и создать на них выключенные копии либо сохранить настройки в библиотеку.

Кнопка **Шаблоны маршрутов** на странице ноды открывает общую библиотеку.
Выберите шаблон и целевые ноды, чтобы создать маршруты сразу на нескольких
нодах. Для предварительной настройки нажмите **Настроить для этой ноды**.
Шаблон можно отредактировать полным редактором маршрута или удалить.
Сохранить текущие настройки как новый шаблон можно и из редактора маршрута.

Шаблон — сохранённый снимок настроек. Созданные маршруты независимы:
изменение или удаление шаблона не меняет их. Автоматической синхронизации
общего маршрута между нодами нет.

Переносятся listener, SNI, серверы и их роли, DNS-пулы, веса, закрепление,
PROXY protocol, лимиты, плавный ввод и ручные backend-директивы. Не переносятся
идентификаторы, история, применённые ревизии, состояние публикации, соединения,
таблицы закрепления и использованный трафик. Новые маршруты всегда выключены.

Перед включением проверьте привязанный listener IP, пути Unix-сокетов,
доступность бэкендов и поддержку параметров агентом целевой ноды. Конфликты
SNI и listener проверяются штатной процедурой включения. Копирование не
заменяет существующие маршруты и не публикует конфигурацию HAProxy.

При копировании на несколько нод результат показывается для каждой.
Успешные копии сохраняются даже при ошибке на другой ноде. Для повторной
попытки остаются выбраны только ноды с ошибками. Если ответ потерян из-за
сети, проверьте списки маршрутов перед повтором: запрос копирования не
является идемпотентным.

Шаблоны хранятся в PostgreSQL (миграция 000056) и доступны только через
административную авторизацию. Изменение, удаление и применение требуют
актуальную версию шаблона. Устаревшая операция получает 409.
