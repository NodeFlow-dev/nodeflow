NODEFLOW — НАЧНИТЕ ОТСЮДА
=========================

1. Для автоматической установки на чистую Ubuntu запустите:

     sudo ./INSTALL-NODEFLOW.sh

   Скрипт проверит, что домен указывает на публичный IP сервера, запросит режим
   доступа, установит Panel с Caddy и сохранит реквизиты в
   nodeflow-credentials.txt домашней папки запустившего пользователя.
2. Для ручной установки откройте 00-START-HERE.html в браузере.
3. Папка 01-PANEL содержит архив Panel и готовые конфиги Nginx/Caddy.
4. Папка 02-NODE-AGENT-UPLOAD содержит Linux amd64 бинарник Agent.

Комплект содержит Agent для linux/amd64. Бинарник для linux/arm64
(nodeflow-node-agent-<версия>-linux-arm64) лежит отдельным файлом в assets
GitHub Release: загрузите его так же, указав архитектуру arm64.

ВАЖНО:
Сначала загрузите файл из 02-NODE-AGENT-UPLOAD в «Настройки → Node Agent»
и опубликуйте подписанный релиз. Без совместимого релиза установка новой
ноды заблокирована.

После этого откройте «Ноды» → «Добавить ноду», укажите IP и SSH-доступ.
Panel один раз подключится по SSH, установит выбранный либо новейший
совместимый Agent и дальше будет управлять нодой по mTLS.
